OTMR RCM dedicated remote startup gate

Control URL (GitHub Contents API):
https://api.github.com/repos/paulopp1234/OTMR-CCF-EDYTOR/contents/OTMR_RCM?ref=main

Request headers:
Accept: application/vnd.github.raw+json
User-Agent: OTMR-CcfEditor/0.3
Cache-Control: no-cache, no-store, max-age=0
Pragma: no-cache

This application checks its dedicated OTMR_RCM file at the root of its own
paulopp1234/OTMR-CCF-EDYTOR repository. This checkout initially contains ALLOW_START.
The whole file must contain one case-sensitive status value after trimming
surrounding whitespace/newlines. Prefixed control lines are unsupported.

Allowed value:
ALLOW_START

Blocked value:
DO_NOT_START

Startup order in source:
1. StartupGate.Check()
2. Download the OTMR_RCM file body from main through the Contents API using
   the headers above and an eight-second timeout
3. Trim surrounding whitespace/newlines from the complete file contents
4. If the value is not exactly ALLOW_START: show blocked message and return
5. ApplicationConfiguration.Initialize()
6. new MainForm()

Fail-closed conditions:
- DO_NOT_START
- missing file / 404
- multiple values or additional content
- empty value
- unknown value
- HTTP failure
- network / DNS / TLS failure
- timeout
- GitHub unavailable

Blocked messages begin: OTMR RCM start is not authorised.
Status is DO_NOT_START for an explicit block, INVALID for empty or unsupported
content, or UNAVAILABLE when the file cannot be retrieved and validated.

Every launch performs a fresh request. No allowed result is cached between
launches, and no local allow fallback exists. HTTP handler injection remains
available to tests without contacting the live control repository.
