# Generated Class 171 configuration exchange (non-transmitting)

## Result and safety boundary

**Full START configuration sequence is safely generatable.**

`OtmrConfigurationExchangeGenerator` constructs all seven writes in memory from
the six validated current-recorder data pages, the explicitly selected
26,600-byte CCF, and protocol transformations repeated in both full HHD
sessions. The generator itself has no transport dependency. It is now consumed
by `OtmrLiveService` only after the controlled-bench preflight documented in
[`CLASS171_OTMR_CONTROLLED_BENCH_INTEGRATION_20260825.md`](CLASS171_OTMR_CONTROLLED_BENCH_INTEGRATION_20260825.md).
`RecorderConfigurationWriteBlocked` remains the failure state whenever that
preflight is incomplete or invalid.

The generator reproduces every byte of the 2026-08-24 START and 2026-08-25
START configuration exchanges. Its restoration mode also reproduces every byte
of the 2026-08-25 STOP cleanup exchange, selecting the recorder values cached
during that cleanup interrogation instead of selected-CCF values for the two
phase-dependent fields.

## Generated writes

| Captured event | Operation | Length | Payload length | START check |
|---|---|---:|---:|---:|
| `000301` | RX `01 0C` acknowledgement | 13 | 1 | `0C` |
| `000312` | configuration page 1 | 267 (`0x10B`) | 255 | `8E` |
| `000335` | configuration page 2 | 267 (`0x10B`) | 255 | `55` |
| `000357` | configuration page 3 | 267 (`0x10B`) | 255 | `6B` |
| `000378` | configuration page 4 | 267 (`0x10B`) | 255 | `74` |
| `000401` | configuration page 5 | 267 (`0x10B`) | 255 | `00` |
| `000423` | configuration page 6 | 210 (`0xD2`) | 198 | `40` |

Every check byte is recalculated as the sum of the payload bytes between STX
and ETX modulo 256. The generated page order is acknowledgement `0C`, followed
by indexed writes `01`, `02`, `03`, `04`, `05`, `06`.

## Continuous-stream transformation

The generator concatenates RX payloads `01 02`, `01 04`, `01 06`, `01 08`,
`01 0A`, and `01 0C`, applies the proven edits to that one continuous stream,
then partitions the result into five 255-byte pages and one 198-byte page. This
preserves all cross-page source bytes.

- The initial recorder bytes `06 00 00 05 C0` become the proven `02` prefix.
- START encodes selected `CCF[0x0231]` as `(FE-value) mod 256` and
  `CCF[0x0263]` as `(03-value) mod 256`.
- STOP restoration applies those same transforms to cached RX `01 02` payload
  offsets `0x86` and `0xB8`.
- The five proven structural removals/zero insertions and terminal `40`
  replacement are applied at their continuous-stream positions.
- Every other payload byte is copied from its identified recorder RX offset.

## Per-byte protocol table

[`CLASS171_OTMR_GENERATED_START_PROVENANCE.csv`](CLASS171_OTMR_GENERATED_START_PROVENANCE.csv)
contains all 1,558 bytes across the seven START writes. Each row gives the
captured event, frame offset, generated value, source category, and exact source
reference. The source totals are:

| Source | Bytes |
|---|---:|
| protocol constant | 51 |
| recorder RX | 1,492 |
| selected CCF | 2 |
| calculated field/checksum | 13 |

The table is regenerated by:

```powershell
& .\tools\Compare-OtmrHhdSessions.ps1 -WriteCsv
```

That script reconstructs the START payload stream from the same explicit rules
and refuses to export if any generated byte differs from either authoritative
START HHD session.

## STOP lifecycle context

Closing the live DTR-high serial port stops realtime immediately. Arrowvale
sends no distinct live-stop command before that first close. It subsequently
opens an RTS LOW / DTR LOW cleanup session and performs the separate restoration
interrogation/write exchange generated above.
